# Impose multiple restrictions to a Cartesian product

An internal function that imposes multiple restrictions to a Cartesian
product. See \`rlazycartesian:::restrict()\`.

## Usage

``` r
restrict_multi(l, restrictions)
```

## Arguments

- l:

  A named list with the combinations for the Cartesian product.

- restrictions:

  A named list of restrictions. See \`restrict_multi()\`.
